# Test corpus

Put 20–40 of your own documents here. This folder is git-ignored apart from this file.

**Mix to aim for:** a few long PDFs (30+ pages), several medium docs (5–20 pages),
a pile of short notes, at least one messy/unstructured file (a transcript or brain-dump),
and **3–4 documents in two versions**.

**Naming convention for versions:** `name__v1.ext`, `name__v2.ext` (double underscore).
The `doc_id` is the name without the suffix, so `rental_agreement__v2.pdf` → `rental_agreement`.
Files without a suffix are treated as version 1.

Supported in Phase 1: `.pdf`, `.md`, `.txt`. Subfolders are fine.

Check your corpus with: `python -m scripts.inventory_corpus`
